# IPSO: Secure and High Performance Transaction Concurrency Control via Hot-path Commutativity

This repository contains the code and experimental setup for our research paper:

**"Secure and High Performance Transaction Concurrency Control via Hot-path Commutativity"**

Submitted to **ICDE 2026** (IEEE International Conference on Data Engineering)

## Overview

IPSO introduces a novel approach to transaction concurrency control that achieves both security and high performance by leveraging hot-path commutativity. Our system addresses the challenge of maintaining strong security guarantees while minimizing performance overhead in concurrent transaction processing.
